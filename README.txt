KEBERAGAMAN LINGKUNGANKU — VERSI REALISTIS

Teknologi: HTML, CSS, JavaScript. Tidak memerlukan framework, npm, atau internet.

CARA MENJALANKAN
1. Ekstrak seluruh folder ZIP ini.
2. Klik dua kali keberagaman-lingkunganku/index.html.
3. Gunakan tombol NEXT > START PETUALANGAN > pilih Misi 1/2/3.
4. Jangan memisahkan index.html dari data.js, script.js, style.css dan folder assets.

Jika ingin menjalankan lebih nyaman di Visual Studio Code, buka folder ini lalu
gunakan extension Live Server, atau jalankan `python -m http.server 8000`.

Aset konten:
- 15 foto pakaian adat berasal dari dokumen referensi yang diberikan pengguna.
- Peta relief berasal dari gambar yang diberikan pengguna (mengandung watermark).
- 15 visual tradisi dan gambar anak merupakan ilustrasi realistis yang dibuat AI,
  bukan foto dokumentasi dan tidak boleh dianggap bukti antropologis.
- Pertanyaan Misi 2 berasal dari materi soal pengguna, dan Misi 3 diadaptasi
  menjadi format benar/salah untuk pemeriksaan otomatis.
- Skor Misi 2 = 2 poin per soal sebagai nilai sementara yang ditetapkan pada implementasi.

Jika hanya ingin mencoba tanpa folder, gunakan file:
Keberagaman-Lingkunganku-Realistis.html
